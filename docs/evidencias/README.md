# Evidencias

Las capturas de esta carpeta deben tomarse **solo con datos ficticios** de los
emuladores (ver "Correr la app contra los emuladores" en el README): cuentas como
`alumno@utng.edu.mx`, la cafetería y la CLABE de `dataconnect/seed_data.gql`.

Antes de agregar una captura:

- Recorta o tapa correos reales, tokens, URLs con `token=` y cualquier dato personal.
- No incluyas comprobantes de pago reales.
- Nombra el archivo por criterio y fecha, por ejemplo `criterio09-sin-sesion-2026-11-10.png`.

Evidencias sugeridas:

| Criterio | Qué capturar |
| --- | --- |
| 9 | Pantalla de login y cierre de sesión con una cuenta de prueba; mensaje de error genérico de un pedido rechazado |
| 9 | Resultado de `npm test` en `test_dataconnect` mostrando las pruebas de permisos |
| 10 | Diagrama del flujo en `docs/integracion-nube.md` |
| 11 | Pestaña *Actions* de GitHub con el workflow `CI` aprobado |
